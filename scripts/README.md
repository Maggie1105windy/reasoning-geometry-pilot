# Scripts

These scripts preserve the executed or preregistered research pipeline.

- `stage-a/`: World coordinate probing and migration checks.
- `stage-b0/`: StepGame audit and frozen split construction.
- `stage-b1/`: Base activation extraction, layer probes, controls and validation.
- `stage-b1_5-b1_6/`: candidate behavior and cross-hop transfer.
- `stage-b2-planned/`: planned Base–post-training comparison; presence of code is not evidence of completed results.

The scripts currently preserve historical server project paths for provenance. Before running in a new environment, replace those roots with a configurable project path and restore external model/data dependencies according to their licenses.
