### graph 一词的具体处理

可以用外部图清楚解释 StepGame：实体是节点、原始关系是有向边、派生关系是沿路径组合。必须把“数据的外部关系图”和“模型内部是否具有图式表征”分开。前者是任务的规范描述，后者是尚待检验的机制假设。

更强的内部证据链可以写成：
1. 在同一状态恢复多个实体对和关系矩阵，而非只解码被问答案。
2. 实体重命名、句序变化后，关系结构仍稳定；控制标签与模板线索。
3. 干预 B→C 的关系，使依赖该边的 A→C 按已知组合规则变化；无关 D→E 保持稳定。
4. 与随机位置、无关边、相同长度替换等对照比较。

即便这些成立，也应使用“支持某种 graph-like 关系表征及其因果使用”，不把完整认知架构视为已证实。

## 二、六篇最相关原始文献：已打开摘要，关键方法/局限打开正文核验

### 1. CoT 可读性与忠实性：奠基而非最新发现

[Lanham et al., Measuring Faithfulness in Chain-of-Thought Reasoning (2023)](https://arxiv.org/abs/2307.13702)

通过给推理链加入错误、改写等方式测量答案对 CoT 的依赖；不同任务/模型差异明显。支持把“写出了推理”与“答案真正依赖该推理”分开。**不能推出**全部 CoT 都无用，也不能把文本编辑的结果直接等同隐藏计算的内容特异性因果使用。报告中可作方法背景，不必详细重复旧文献。

### 2. “RL 主要提高已有轨迹采样效率”的实证观点

[Yue et al., Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model? (2025, v5)](https://arxiv.org/abs/2504.13837)

以多模型/算法/数学、编程和视觉推理的大 k pass@k、覆盖与困惑度分析，认为其研究的 RLVR 设置主要提高已有轨迹的抽样效率。**不能推出**所有 RL、任务与训练方式均无法产生组合泛化；“有限采样未观察到”也不是概率支持严格为零。在 StepGame 八选一任务，单纯多次答案命中尤其易受猜测污染。

### 3. 同时验证过程与答案，会改变对能力边界的判断

[Wen et al., Reinforcement Learning with Verifiable Rewards Implicitly Incentivizes Correct Reasoning in Base LLMs (2025, v2)](https://arxiv.org/abs/2506.14245)

[正文](https://arxiv.org/html/2506.14245v2)

引入 CoT-Pass@K，比较 Qwen2.5-32B 与 DAPO，强调答案正确不保证过程正确；观察到训练早期过程质量改善。过程检查使用专门 LLM 多次判断并有人审，仍有判错风险。**不能直接推出**本项目已具备正确过程评估，也不能拿文中“前 20 个 PPO-style training steps”（每步 16 次梯度更新）作为 Qwen3 或所有后训练的能力出现时间。

### 4. 最新组合泛化视角：SFT 与 RL 可能互补

[Kong et al., From Reasoning Traces to Reusable Modules: Understanding Compositional Generalization in Language Model Reasoning (2026, v2)](https://arxiv.org/abs/2606.18089)

[正文](https://arxiv.org/html/2606.18089v2)

在层级潜在选择模型及受控实验中，SFT 提供复合轨迹中的模块材料，RL 帮助识别模块并在新组合中重用。为“关系组合是否改善”提供可检验替代假设。**不能推出**真实 Qwen3 内部已有这些离散模块；论文主动说明实验简化，向数学、代码等丰富领域推广仍待验证。

### 5. 最新受控训练全链条：难度可能决定 RL 的作用

[Shen et al., Understanding Reasoning from Pretraining to Post-Training (2026, v2)](https://arxiv.org/abs/2607.16097)

[正文](https://arxiv.org/html/2607.16097v2)

以棋类 5M–1B 模型追踪预训练→合成推理 SFT→RL：容易题强化原有正确偏好，困难题可提升 SFT 中极少出现的正确动作。支持按难度、初始正确轨迹质量分层。**不能说**困难题正确动作的支持原来严格为零；小词表、精确奖励、最高 1B 等设置限制定量外推，论文的主要数学迁移结果也不能直接等同 StepGame。

### 6. 最贴近下阶段的因果方法

[Bhupatiraju & Nyaupane, Are Stated Reasoning Steps Causally Load-Bearing? (2026-09-22, v1)](https://arxiv.org/abs/2609.27038)

[正文](https://arxiv.org/html/2609.27038v1)

在 Qwen3-4B/1.7B 的 2–6 hop 合成查找任务中，对模型自行生成的步骤 span 做残差流反事实 patch，并要求答案变到预先确定的目标；设置随机位置、prompt 事实、答案后、打乱 donor 对照。**不能外推**为 Qwen3-8B StepGame 已验证；只对正确且格式合格子集操作，且早层 patch 可能近似 token 身份替换。它最适合支持本项目“先明确反事实目标，再做有特异性对照”的设计。

此文题注为 “NeurIPS 2026, Interpretability as a Science”，综合报告宜称 2026 年预印本，不自行升级为 NeurIPS 主会录用。原文把 76.9/83 说成约 96%，与算术不一致；建议避免复述这个归一化比例。若用效果数字，应写清确切层位、样本筛选和任务，不能只摘一个百分数。

## 三、文献综合后，下一阶段应问什么

建议研究问题：

> 后训练如何改变正确关系状态的形成、保持与使用？变化主要体现为正确轨迹选择的改善，还是在新组合上的有效关系计算提升？

这比预设“RL 只重加权”或“看见某句话就发现能力诞生”更可检验。

必须区分三条时间轴：
- **生成 token 时间**：固定权重下，关系状态何时形成、何时可读、何时被使用。
- **训练 checkpoint 时间**：同谱系 Base/SFT/DPO/RLVR 及中间 checkpoint，变化发生在哪个阶段/区间。
- **因果检验时间**：对指定状态干预后，能否发生预期的答案改变。

可先用现有轨迹标记“首个非平凡正确关系状态、首个正确 query 方向、稳定保持或再次丢失”的语义节点；不能用高频 wait/maybe 当能力出现的时间标记。首先将最终正确与过程有效分开，尤其检查查询方向反转、单位距离约定、无根据假设和循环。

共享轨迹 token 级 Δlog p 的作用是测量同一段文本在不同 checkpoint 下的条件支持变化。需要同时包含正确与匹配错误轨迹，分开关系计算、修正、答案、格式和 EOS token。高条件似然不等于模型会自行生成该轨迹；跨模型几何还需控制坐标不对齐、tokenization 和位置。当前 thinking/non-thinking 对比是同权重协议比较，不能直接回答后训练如何改变模型。

不建议立即倾倒全部 32K×全部层激活。先从 20–30 个有明确诊断类别的样本、少量语义节点和层做可复现的小原型，再决定全面行为确认和同谱系扩展。StepGame 可作结构化机制分支，原先数学/代码可验证奖励的总研究主线仍需保留。
