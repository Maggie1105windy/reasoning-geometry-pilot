# Stage B2.3 阶段任务汇报稿

**汇报题目：Qwen3-8B 自由生成与思考模式的空间多跳推理行为评测**

用途：课题组阶段汇报；正文可直接用于汇报或拆分为约8页PPT。整理日期：2026-10-13。正文区分已完成实验、复盘判断和后续建议，不将后续建议写成已经执行的任务。

## 一、研究背景与阶段目标

本项目关注大语言模型后训练如何改变推理过程，重点研究正确性信号能否更早被读出、正确推理轨迹是否被稳定和重加权，以及这些表征变化是否对最终正确性具有因果作用。

在前期StepGame空间推理实验中，我们发现，模型内部关系信息的可读性与实际答题表现并不完全一致。同时，输入接口、候选答案的token长度和评分方式会明显影响行为结果。因此，在继续投入隐藏状态分析之前，需要先确认评测协议是否合适，以及目标模型是否具备足够的多跳任务表现。

Stage B2.2采用原生聊天模板下的候选似然评分，Qwen3-8B的h2–h5等权准确率为18.53%，尚未确认其强推理研究资格。B2.3在此基础上提出两个问题：

1. 改用自由生成后，模型的多跳表现是否优于候选似然评分？
2. 同一模型开启thinking模式后，是否进一步改善多跳自由生成表现？

本阶段定位为**行为资格与评测协议校准**，为后续机制研究确定可靠的行为基础。

## 二、本阶段完成的任务

本阶段围绕数据与协议冻结、生成实验、结果分析和独立验证完成了一套完整流程。

| 自由生成协议建设 | 新增非思考FG-N与思考FG-T，固定最终答案格式与解析规则 | 建立统一生成、解析、统计及失败处理流程 |
| 长度与显存测试 | 完成初始生成测试与RTX3090批量运行测试 | 按预设截断规则将后续总输出上限统一定为2048 token，主运行batch size为8 |

## 三、实验设计

### 1. 数据与模型

使用冻结的2063条StepGame题目，h1–h5分别为712、505、422、282和142条；h表示关系组合步数。模型为**同一个后训练的Qwen/Qwen3-8B**，使用BF16精度，未进行额外训练。

### 2. 实验条件

| 条件 | 答案产生方式 | thinking | temperature / top-p |
|---|---|---|---|
| B2.2 Native-Sum参照 | 对预设关系候选进行似然评分 | 关闭 | 不涉及自由生成采样 |
| FG-N | 原生聊天模板自由生成 | 关闭 | 0.7 / 0.8 |
| FG-T | 原生聊天模板自由生成 | 开启 | 0.6 / 0.95 |
| 匹配解码对照 | 两模式均自由生成 | 仅开关不同 | 均为0.6 / 0.95 |

自由生成条件的top-k均为20，min-p为0。FG-N与FG-T主实验采用各自的官方采样配置，因此全量比较不仅改变模式，也改变采样参数；匹配解码子集用于控制这一差别。

thinking与non-thinking使用相同权重，区别在聊天模板中的模式信号及随后的生成过程。本实验没有比较Base与后训练模型，也没有比较SFT、DPO和RLVR阶段。

### 3. 评价原则

使用冻结的解析器提取最后一条有效的`Final answer: <relation>`行，接受八种规范空间关系，解析失败计为错误。分别计算各hop的准确率、Macro-F1、平衡准确率和最终答案解析率；主要多跳指标是**h2–h5四个hop的等权平均**。

这种设计避免样本较多的一步题掩盖多跳任务表现，并把答题错误与未能交付合法答案的问题分别记录。

## 四、主要实验结果

### 结果一：自由生成协议改善了多跳行为测量

| h2–h5等权指标 | B2.2候选评分 | FG-N非思考生成 | FG-T思考生成 |
|---|---:|---:|---:|
| 准确率 | 18.53% | 25.65% | 3.52% |
| Macro-F1 | 12.36% | 25.65% | 6.17% |
| 平衡准确率 | 15.74% | 25.13% | 3.40% |
| 最终答案解析率 | 100%（封闭候选） | 92.48% | 4.37% |

FG-N比候选评分的准确率高**7.12个百分点**，配对95%区间为**3.85–10.55个百分点**。这表明答案产生协议会影响模型的可观察表现，应结合自由生成评估任务适配性。

不过，两种协议还涉及最终格式指令和答案产生方式的差异，这一结果不能直接归因于内部推理机制改善。原预设“候选评分低估行为”的明确判定要求更高的提升与解析率，因此正式判定仍为`UNCERTAIN`。

### 结果二：非思考模式存在明显的一步与多步行为差距

| hop | FG-N准确率 |
|---|---:|
| h1 | 70.22% |
| h2 | 33.07% |
| h3 | 23.93% |
| h4 | 23.05% |
| h5 | 22.54% |

模型的一步关系判断明显好于多步关系组合。FG-N虽然改善了行为测量，仍未达到本项目预设的强推理准入门槛。这为后续定位组合、状态保持与答案读出瓶颈提供了问题线索，但还没有分离它们的内部机制。

### 结果三：thinking结果受到严重生成截断限制

在2048-token总输出上限下，FG-T的多跳准确率为3.52%，比FG-N低**22.13个百分点**，95%区间为**−24.87至−19.51个百分点**。匹配采样参数后，pilot多跳准确率仍为FG-N 29.5%、FG-T 3.5%，说明采样参数差异不足以解释全部结果。

更关键的现象是：FG-T在h2–h5的达上限率分别为**88.91%、97.16%、97.87%和98.59%**，思考token中位数均约2047。多数样本在思考尚未完成时耗尽预算，无法交付最终答案。

逐条复核显示，全量FG-T的1665条无效答案全部同时达到上限且没有正常EOS结束；其余398条正常结束且可解析，其中372条正确。**这些完成样本有强选择偏差，不能把其条件正确率当作总体能力。**

所以，本阶段可以明确报告“thinking在当前2048-token配置下没有改善端到端表现”，但尚不能判定其充分预算下的推理能力，也不能直接将长输出归为过度思考。

## 五、阶段成果、结论与不足

### 1. 已形成的成果

- 建立可复用的原生自由生成与thinking行为评测流程。
- 完成数据、模型、提示词、解析器、采样配置与门槛的审计和冻结。
- 保存完整生成文本、token IDs、逐题标签、终止信息、运行清单与恢复shards。
- 形成分hop结果、统计区间、错误分析、六张图及正式阶段报告。
- 识别出评测协议依赖、多跳行为瓶颈和有限预算输出完成失败三个关键问题。

原阶段独立验证为`PASS_WITH_LIMITATION`。2026-10-13复盘另外全量读取15个JSONL、6166条生成记录，并重算108条公开bootstrap区间，核心结果与原表一致。6166条包括smoke、pilot、matched与full，不是6166个独立测试题。

### 2. 正式门控结论与解释范围

| 判定项目 | 原阶段结果 | 汇报解释 |
|---|---|---|
| 候选评分是否低估行为 | UNCERTAIN | 自由生成有改善，但未满足完整预设判定条件 |
| thinking是否改善自由生成 | NO | 限定于当前提示、采样与2048-token预算 |
| 当前正常使用任务适配性 | WEAK | FG-N多跳能力和答案解析率尚未通过强门槛 |
| 是否适合强推理机制研究 | UNCERTAIN | 充分预算thinking能力仍未完成评估 |

原报告选择分支C，建议下一步行为门控Qwen3.5-9B；该模型在本阶段尚未下载或运行。复盘后的研究建议是先补足Qwen3-8B预算校准，再依据结果决定候选模型比较。

### 3. 目前的不足

本阶段仍是行为评测，没有新开展隐藏状态提取、正确性probe、轨迹几何或激活干预。因此，不能据此声称已经证明后训练让正确性更早可读、稳定了正确轨迹，或形成了具有因果作用的空间表征。

此外，thinking大量截断使主结果同时包含推理能力和输出完成能力；主实验的模式与采样配置也需要结合matched子集解释。复现说明中的边界字段、批次随机种子及本地环境档案仍需补充完善。

## 六、下一阶段安排建议

**第一步：完成预算与停止诊断。** 用小规模分层样本测试2K/4K/8K/16K，必要时32K，联合报告正确率、答案解析率、think关闭率、截断率和生成成本。区分预算不足、格式失败、有效答案错误与重复探索。所有变化作为新实验记录，保留B2.3结果。

**第二步：依据校准结果确定机制研究对象。** 若Qwen3-8B在可完成条件下通过行为门槛，就进入小规模机制pilot；若能够完成但多跳仍弱，再门控Qwen3.5或其他候选。新模型须重新审计架构和生成协议。

**第三步：回到总研究问题。** 在行为基础可靠后，分别研究关系状态和最终正确性信号；在同谱系Base/SFT/DPO/RLVR上分析共享轨迹的token级Δlog p与几何变化；最后通过同模型反事实激活替换、消融或方向干预检验因果作用。StepGame保留为结构控制场景，数学与代码保留为总题的确认和迁移场景。

## 八、约2分钟口头汇报稿

本阶段我们完成了Stage B2.3，也就是Qwen3-8B在StepGame上的自由生成与思考模式行为评测。开展这一步的原因是，前期候选似然评分下的多跳表现较弱，而评分方式和输入接口本身会影响结果。因此，在继续做隐藏状态和机制分析之前，我们需要先校准行为评测，确认模型是否适合成为研究对象。

实验继续使用冻结的2063条题目，在同一个后训练Qwen3-8B权重上，分别测试非思考自由生成和思考自由生成，并完成了三种子pilot、匹配采样参数对照、全量运行和独立验证。

结果有两点。第一，非思考自由生成的多跳等权准确率从候选评分的18.53%提高到25.65%，说明评测协议确实影响可观察表现。但一步准确率为70.22%，三到五步只有约23%，模型仍存在明显的多跳瓶颈。

第二，思考模式在2048-token上限下只有3.52%的多跳准确率，但这一低分受到严重截断限制。全量1665条无效答案都在达到上限时尚未完成，不能据此认定思考模式本身没有能力；已经完成的样本也存在选择偏差，不能代表总体。

所以，本阶段的主要成果是建立了可复用的生成评测与审计流程，获得了完整行为数据，并明确了协议、多跳能力和输出完成这三个问题。下一步优先校准生成预算，在确认行为可靠之后，再研究正确性信号出现时间、后训练对轨迹的稳定与重加权，以及几何变化对最终正确性的因果作用。

## 九、备份页与汇报口径

### 必须保留的解释

- h2–h5主指标是四个hop的等权平均；不能与全部2063题的总体准确率混用。
- FG-N与FG-T为同一后训练权重的模式比较；不能解释成Base/SFT/DPO/RLVR比较。
- `PASS_WITH_LIMITATION`意味着结果通过原阶段检查且存在解释限制；不等于强行为门槛通过。
- “未通过强门槛”表示目前不适合直接投入大规模机制采集，不能证明内部空间信息不存在。
- thinking完成子集的高正确率不能用于宣称高多跳能力；长输出本身也不能证明过度思考。
- 最新文献可作为后续设计依据，不能作为本阶段已获得的实验成果。

### 核心阈值与统计

项目强目标门槛：h2–h5等权准确率≥35%、Macro-F1≥30%、平衡准确率≥30%、答案解析率≥98%，并要求无关系类别塌缩、各多跳层优于多数类等。这是项目的资源准入标准，不是通用能力认证。

原统计使用2000次配对bootstrap。测试集每行story_group_id唯一，因此此数据上的聚类重采样实际等价于配对按行重采样；区间未包含改变预算、模型版本或全量生成seed带来的不确定性。

### 复盘发现的文档与展示问题

- 原`generation_stats.csv`沿用旧think边界标志，FG-T完成率显示为0；独立重建总体完成率为19.29%。最终答案准确率不依赖该旧字段。
- 报告的逐行随机种子说明与实际batch size 8批次种子不一致，复现需以执行manifest为准。
- 原8×8混淆矩阵排除INVALID；FG-T矩阵只包含398个有效输出，须与解析率/截断率一起展示。
- 当前本地档案缺少完整模型与部分历史产物，支持结果重算，不能声称已在本地原样重跑生成。

以上内容用于备份答疑和后续规范化，不把文档维护问题当作内部推理机制结论。
